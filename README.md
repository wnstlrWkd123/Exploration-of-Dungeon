# Exploration_of_Dungeon

유니티의 다양한 기능을 실습을 통해 익히기 위한 프로젝트입니다.

## 📌 프로젝트 소개

- **목적**: Unity와 C#의 주요 기능들을 직접 구현하며 학습하기 위한 개인 프로젝트

## 🛠️ 사용 기술

- Unity 2022.3.17f1
- C#
- Unity Input System
- ScriptableObject
- Raycast
- ForceMode

## 🎮 주요 기능

- **플레이어 이동 및 점프**
  - WASD로 이동, Space Bar로 점프(짧게 누를시 약한 점프 가능)
  - 점프는 Raycast를 이용해 지면 체크 후 수행
  - 이동 시 점점 속도가 증가하며, 최대 속도를 제한함

- **상호작용 시스템**
  - 상호작용 가능한 오브젝트 근처에 가서 마우스를 갖다 대면 Raycast를 통해 메시지 표시
  - 마우스 왼쪽 클릭 시 패널이 열리고, 오브젝트에 따라 다른 효과의 "사용하기" 버튼 제공
    - 체력 회복
    - 스피드 증가 (30초)
    - 점프력 증가 (30초)

- **점프대 기능**
  - 특정 발판에 닿으면 ForceMode를 이용해 강하게 점프하게 함

- **아이템 시스템**
  - ScriptableObject를 활용해 다양한 아이템 정의 및 효과 처리

## 🧪 실행 방법

- Unity 2022.3.17f1 이상에서 프로젝트 열기
- `SampleScene`을 실행하면 플레이 가능
